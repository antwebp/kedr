# Таежный Дар — сайт кедровой продукции

Одностраничный сайт компании «Таежный Дар»: кедровая шишка, масло и орех из уральской тайги.

## Стек

- Статический HTML/CSS/JS — без сборки и зависимостей
- Адаптив: десктоп (≥1200), планшет (768–1199), мобильный (≤767)
- Vanilla JS: модалки, FAQ-аккордеон, маска телефона, валидация форм, плавные скролл-переходы, reveal-анимации

## Структура

```
site/
├── index.html          # главная страница
├── privacy.html        # политика конфиденциальности
├── terms.html          # пользовательское соглашение
├── css/styles.css      # все стили (дизайн-токены в :root)
├── js/main.js          # вся логика
└── assets/             # изображения, favicon
```

## Локальный запуск

```bash
cd site
python3 -m http.server 8741
# → http://localhost:8741/index.html
```

## Публикация

Загрузка формы заявки — имитация (место для реального API помечено комментарием в `js/main.js`, функция-обработчик `.lead-form`).

Соцсети в футере ведут на главные страницы сетей — заменить ссылки на реальные профили при появлении.
